# 오늘의 할 일 (To-Do)

HTML · CSS · JavaScript만으로 만든 할 일 웹 앱입니다. 서버 없이 `index.html`을 열면 바로 동작합니다.

## 기능

1. 할 일 입력 후 Enter 또는 "추가" 버튼으로 등록 (공백만 입력하면 추가되지 않음)
2. 체크박스로 완료 표시 (완료되면 취소선)
3. 삭제 버튼
4. 전체 / 진행중 / 완료 필터 탭
5. 남은 할 일 개수, 오늘 달성률 게이지
6. 새로고침해도 목록 유지 (브라우저 localStorage)
7. 다크 모드 (선택 상태도 유지)

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| index.html | 화면 뼈대 |
| style.css | 모양과 색 (라이트/다크 변수) |
| app.js | 동작: `todos` 배열 → `render()` |

## 올리기

`push-to-github.bat`을 더블클릭하면 커밋 후 GitHub에 올라갑니다.
